데이터 연결

01 SNS 국가별 분석 JSON

한국(KR)·중국(CN)의 SNS 분석 자료를 서버에서 자동으로 연결합니다.

선택한 국가의 SNS 데이터만 교체합니다. 국가 정보가 없는 항목은 위에서 지정한 국가에 연결됩니다.

JSON 구조와 집계 기준
influencers: [{ id, handle, countryCode? }]
posts: [{ postId, influencerId, postedAt, permalink, caption?,
  likeCount, commentCount,
  media: [{ mediaId, index, mediaType, mediaUrl, hf_url?,
    thumbnailUrl?, mediaPermalink? }] }]
images: [{ mediaId, postId, analysisStatus,
  items: [{ classCode, categoryCode, garments: [{
    subcategoryCode, subcategoryLabel,
    designTypeCode, designTypeLabel,
    attributes: { form: [{ code, label }], color: [...], ... }
  }] }] }]

큰 ID는 문자열이어야 합니다. 고유 게시물 수로 중복 이미지를 제거하며, 단일 속성은 선택한 디자인과 같은 아이템에서 확인된 값만 연결합니다. NONE·UNKNOWN은 신호에서 제외합니다.

03 이미지 폴더

원본 주소가 없거나 만료되었다면 이미지 폴더를 연결하세요. mediaId와 같은 파일명으로 매칭합니다.

연결된 폴더 없음

04 비공개 Hugging Face 이미지

공개 이미지에는 토큰이 필요하지 않습니다. 비공개 이미지는 서버를 통해 자동으로 연결하며 토큰은 브라우저에 전달하지 않습니다.

SNS·AI 분석·쇼핑몰 자료는 배포된 서버에서 자동으로 연결합니다. 비공개 이미지는 서버가 대신 읽으며, 토큰은 브라우저에 전달되지 않습니다. 새로고침하면 최신 배포 자료를 다시 연결합니다.
